Privacy Policy

Last updated: October 5, 2026

What This App Is

Bullitt Backup is a personal, single-user backup tool created and used only by Jason Kalani Wong. It is not offered to the public.

What It Accesses

The app connects to the owner's own Google Drive account, using Google's sign-in, and only to store backup copies of the owner's own files there. It does not access anyone else's Google account or data.

Data Collection And Sharing

No data is collected from any other person. No data is shared with, sold to, or disclosed to any third party. Backed-up files stay in the owner's own Google Drive. Sign-in tokens are kept only on the owner's own computer.

Google API Services

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
